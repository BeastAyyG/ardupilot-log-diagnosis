# Evidence Ledger

**Rule:** every performance number in the README, model card or a paper must
appear in this ledger with:
- the committed artifact it comes from;
- the single command that regenerates it;
- the commit it was produced at.

A number without a complete row is not a result. It must not be published,
or it must be marked "unverified".

Status values:
- **Reproducible:** the command regenerates the artifact from committed code
  and data.
- **Text-only:** the number exists in documentation, but its artifact or
  inputs are missing from the repository.
- **Retracted:** see [CORRECTIONS.md](../CORRECTIONS.md).

## Why the headline figures are "Text-only"

The full git history was fetched on 2026-09-25 (234 commits, all branches).

**What exists in history:**
- `training/ece_report.json` at three commits:
  - `65376f8` (2026-03-16): ECE 0.0001 on 140 samples, the retracted BASiC figure (C1).
  - `cc72a71` (2026-07-24): ECE 0.127 on 22 saved-holdout flights.
  - `6f0bc32` (2026-08-19): ECE 0.042 on 535 samples, target 1.0.
- On branch `origin/goal-loop-results` (`3b83b19`):
  - `data/cohorts/cohort_manifest.json`, a real-only, thread-grouped cohort
    assignment that excludes BASiC.
  - `data/evaluation/freeze_manifest.json`, with source commit `e6baff5`.

**What was never committed to any branch:**
- `models/candidates/**`, including the `v2_111` and `v3_unambiguous`
  manifests that the cohort manifest cites.
- `training/candidates/**`.
- `data/ablation/ablation_report.json`.

So the 0.500 / 0.153 figure was produced from artifacts that exist only on
the author's local machine. If those folders still exist there, commit their
JSON manifests (not raw logs) and update the rows above. If not, the figure
must be regenerated by `training/paper_eval.py`.

**Caveat on the cohort manifest:** its `evaluation_holdout` includes thread
142590, the former "wild holdout". That log was used for rule tuning and
training (CORRECTIONS.md, C5), so it must move out of any evaluation holdout.

**Other blockers:**
- The real forum logs are Git LFS pointers in `data/kaggle_backups/` and are
  absent elsewhere. The cohort manifest reports 174 unique real logs on the
  author's disk.
- `training/groups.csv` has only a `source_log` column, with no
  `source_url` or `source_type`.
